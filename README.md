# personal-goals
Personal Goals Tracker tracks and visualizes your goals.

# Features
    - Your Personal Whiteboard: Similar to Excalidraw, you can have your own personal whiteboard here.
    - Daily Goals Tracker: Set a template for daily goals, copy them over for the weekend easily.
    - Monthly+ Goals: Create an overarching goal and give it a deadline.
    - Eat the Elephant: Divide your goal into subgoals.
    - Visualize your progress using pretty pie-charts and professional animations.
